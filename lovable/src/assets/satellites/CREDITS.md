# NASA spacecraft models

- Terra: https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Terra — NASA 3D Resources, public domain / free and without copyright per repository README. Terra carries MODIS; the scene labels it Aqua, the MODIS host used in the harmonized record, because Aqua shares the same EOS spacecraft family and no Aqua model is used here.
- Suomi NPP: https://science.nasa.gov/3d-resources/suomi-national-polar-orbiting-partnership-suomi-npp/ — NASA/Brian E. Kumanchik; NASA/Christian A. Lopez. NASA 3D Resources, public domain / free and without copyright per repository README. Suomi NPP carries VIIRS; the scene labels it S-NPP → NOAA-20, the VIIRS hosts used in the harmonized record, and the model does not depict NOAA-20.
- Usage guidelines: https://www.nasa.gov/nasa-brand-center/images-and-media/ . No NASA endorsement is implied. Scene orbital paths, relative sizes and animation timing are illustrative, not physical tracking data.
